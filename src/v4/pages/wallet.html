Play money
real wallet

This is the wallet that will plug into every Kudoken spot. Right now it runs on Base Sepolia, a test network, so you can poke at it without risking a cent.

Have a go

  • Connect with MetaMask, Coinbase Wallet or any browser wallet.
  • See your test KDU balance. It starts at zero, which is normal.
  • Send test KDU to a friend. You need a little free test ETH for the fee, from a Base Sepolia faucet.

Nothing here is real money. Test tokens have no value and cannot be swapped for real KDU. Real KDU lives on Ethereum, see the token page.
